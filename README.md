# Purpose
A group project to design, build, deploy, and document a professional WordPress website for a real client.
This Assessment focuses equally on the product and the development process (workflow, documentation, version control, teamwork).
This repository contains our team’s custom WordPress theme and all project documentation.
It provides a complete record of our development process, including version control, workflow decisions, and environment setup.
It supports collaboration by tracking contributions, commits, and project management activity.
It documents how to install, develop, test, and deploy the site across local, staging, and production environments.
It acts as a professional handover package so another developer can continue the project without guesswork.
It ensures transparency for markers by making our workflow, decisions, and progress visible throughout the project.
# Core Requirements
Our team will deliver:
A custom WordPress theme built from a recognised starter theme
Local, staging, and production environments
A public GitHub Classroom repo
A public project management board (Trello or GitHub Projects)
Markdown documentation in the repo root
A recorded workflow presentation
